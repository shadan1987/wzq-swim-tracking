# 王子期成长追踪系统

一个集游泳比赛成绩、训练记录、学习成绩、身高体重发育于一体的综合追踪平台。

## 快速开始

### 本地运行（推荐）

1. 安装 [Node.js](https://nodejs.org/)（v18+）
2. 打开终端，进入项目目录：
   ```
   cd swim_scores
   node server.js
   ```
3. 浏览器打开 `http://127.0.0.1:8765/swimming-comparison.html`

### 纯前端模式（无后端）

直接双击 `swimming-comparison.html` 用浏览器打开，数据保存在浏览器 localStorage 中。

## 功能总览

### 🏊 比赛成绩

| 功能 | 说明 |
|------|------|
| 成绩记录 | 支持批量添加、Excel上传、JSON导入导出 |
| 趋势图表 | 按比赛日期的成绩变化趋势 + 按项目的进步趋势 |
| 选手对比 | 搜索对比选手，一键对比成绩 |
| 等级达标分析 | 对比2025新版《游泳运动员技术等级标准》男子50米池标准，计算与三级/二级/一级/健将的差距，基于历史进步速率预测达级时间 |

### 🏋️ 训练记录

| 功能 | 说明 |
|------|------|
| 每日训练 | 记录训练日期、时长、强度、内容 |
| 测试成绩 | 按项目+池型（25米池/50米池）录入训练后测试成绩 |
| 每周节奏 | 最近4周训练频率统计 + 本周日历视图 |
| 达级差距 | 测试成绩自动对比等级标准，显示与各级别差距 |
| 训练明细 | 全部训练/测试记录明细表 |

### 📚 学习记录

| 功能 | 说明 |
|------|------|
| 成绩录入 | 日期、学期、考试类型（测验/月考/期中/期末）、科目、分数、满分、排名 |
| 科目概览 | 每科最新成绩、平均得分率、进步趋势 |
| 成绩曲线 | 每科独立的得分率趋势折线图（期末红点/期中橙点/测验科色） |
| 学期汇总 | 按学期×科目矩阵展示期中期末成绩 |
| 明细表 | 全部成绩记录明细，含得分率颜色标识 |

### 📏 身高体重

| 功能 | 说明 |
|------|------|
| 生长曲线 | 身高/体重随年龄变化曲线，对比中国儿童发育标准P3/P50/P97百分位 |
| 年度增长 | 每年身高体重增长幅度，对比正常发育速率 |
| 数据持久化 | 16条记录（2015年出生至2026年7月） |

## 文件结构

```
swim_scores/
├── server.js                    # Node.js 后端服务（零依赖）
├── swimming-comparison.html     # 主页面（前端全部功能）
├── swimming_data.js             # 初始游泳成绩数据
├── data/
│   └── store.json               # 持久化数据（游泳成绩+身高体重+训练记录+学习记录）
├── swiminfo_scraper.js          # swiminfo.cc 成绩抓取脚本
├── swiminfo_bookmarklet.js      # 浏览器书签版抓取脚本
├── install_bookmarklet.html     # 书签安装页面
├── grade_men.jpg                # 运动员等级标准参考图
└── README.md                    # 本文档
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/growth` | GET | 获取身高体重列表 |
| `/api/growth` | POST | 新增身高体重记录 |
| `/api/growth?id=xxx` | DELETE | 删除指定记录 |
| `/api/swimscores` | GET | 获取游泳成绩列表 |
| `/api/swimscores` | POST | 整体替换游泳成绩 |
| `/api/training` | GET | 获取训练记录列表 |
| `/api/training` | POST | 新增训练记录（每日训练/测试成绩） |
| `/api/training?id=xxx` | DELETE | 删除指定训练记录 |
| `/api/study` | GET | 获取学习记录列表 |
| `/api/study` | POST | 新增学习记录 |
| `/api/study?id=xxx` | DELETE | 删除指定学习记录 |

## 数据更新指南

### 游泳比赛成绩
- 方式1：页面工具栏「+ 批量添加」手动输入
- 方式2：页面工具栏「📤 上传Excel」上传 .xls/.html 文件
- 方式3：使用 swiminfo.cc 书签一键抓取（见 `install_bookmarklet.html`）

### 训练记录
- 切换到「🏋️ 训练记录」标签页
- 选择「每日训练」或「测试成绩」页签，填写表单后点击「＋ 添加」

### 学习成绩
- 切换到「📚 学习记录」标签页
- 填写日期、学期、考试类型、科目、分数等信息，点击「＋ 添加」

### 身高体重
- 切换到「📏 身高体重」标签页
- 填写测量日期、身高、体重，点击「＋ 添加记录」

## 等级标准说明

- 依据：2025年1月1日起施行的《游泳运动员技术等级标准》（男子50米池）
- 标准数据位于 `swimming-comparison.html` 的 `GRADE_STANDARDS` 变量中
- 如需调整某项目标准，修改该变量即可
- 参考图片：`grade_men.jpg`

## 技术栈

- 后端：Node.js 内置模块（零第三方依赖）
- 前端：原生 HTML/CSS/JavaScript + Chart.js（CDN）
- 数据存储：JSON 文件（`data/store.json`）
- 浏览器兼容：Chrome / Edge / Firefox 等现代浏览器

## 分享与部署

### 分享给他人
1. 将整个 `swim_scores` 文件夹打包为 zip
2. 对方解压后安装 Node.js，运行 `node server.js` 即可

### 部署到服务器
1. 将文件上传到服务器
2. 修改 `server.js` 中的 `PORT` 和 `127.0.0.1` 为实际端口和地址
3. 用 `node server.js` 或 PM2 等进程管理器启动
4. 配置反向代理（如 Nginx）指向该端口
